# Contributing

1. Open or clarify an issue before starting a substantive task.
2. State its goal, scope, acceptance criteria, and dependencies.
3. Choose a responsible person in Assignees. Select Ready only when the work can start.
4. Move the issue to In progress when implementation actually begins.
5. Work on a branch and check behavior against the acceptance criteria.
6. Move to In review when another team member can examine the result.
7. Follow the course's review process, integrate accepted work, and close the issue
   as completed when its acceptance criteria are met.

AI assistance is optional. Keep any assistance bounded to the agreed task, inspect
its output, and disclose what was used and how it was verified. Do not use AI to
generate a whole student project and then invent a development history afterward.

This scaffold has no application or automated tests yet. Each implementation issue
requires relevant tests. Add CI as the first executable components are introduced.
