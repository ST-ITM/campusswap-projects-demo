# Code of conduct

Treat contributors respectfully. Discuss the work without personal attacks,
harassment, or discrimination. Give specific, constructive feedback and allow
others to ask questions and explain their decisions.

For this course demonstration, raise concerns privately with the course instructor
using the contact route published in eClass. Do not post private student information
in public issues. A team reusing this text must adapt the reporting route to its
actual project and maintainers.
