# CampusSwap

A desktop application that helps students list and find used items for exchange.

## Planned Features

- Create listings with a title, category, and description.
- Browse available items.
- Search listings by title.
- Mark items as exchanged.
- Save listings locally between sessions.

## Listing Categories

- Books
- Electronics
- Clothing
- Other

## Technology

- **Python** for application logic
- **Tkinter** for the desktop interface
- **SQLite** for local storage

## Scope

The first version supports creating, browsing, searching, and updating the availability of listings. Accounts, payments, messaging, and online deployment are outside the initial scope.
